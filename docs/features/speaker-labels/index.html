How do I add speaker names to a transcript?

Open the note in Murmur, tap Edit and choose a speaker for a line. Type a name once and reuse it on other lines. Murmur colours each speaker, shows the names in the transcript and includes them when you export to text or Markdown.

In the app

How it works

Tap Edit on a note

Each line shows its speaker.

Pick or type a name

Apply it to the lines that person said.

Read and export

Names and colours carry through to summaries and exports.

Details

What you get

Colour per speaker

Each name gets a colour from the Murmur palette so you can scan a long transcript.

Reuse names

Names you add in a note are offered again for its other lines.

Talk time

On iPad and Mac, bars show each speaker's share of the conversation.

In every export

Text and Markdown exports keep the names next to each line.

FAQ

Frequently asked questions

Does Murmur detect speakers automatically?

Not today. You label speakers yourself in the editor, which takes a few taps and stays accurate.

How many speakers can a note have?

As many as you need. Colours repeat after five speakers.
