How do I export a transcript as subtitles?

Open the note in Murmur, tap Share and choose Subtitles. Murmur writes an SRT file with each line's start and end time, which video editors such as Final Cut Pro, Premiere Pro, DaVinci Resolve and YouTube accept. You can also export text, Markdown or the audio.

FAQ

Frequently asked questions

Is exporting free?

Exporting notes up to two minutes long is free. Murmur Pro exports notes of any length.

Can I drag a note out on Mac?

Yes. Drag a note from the list into Finder or Mail to get a text file.
