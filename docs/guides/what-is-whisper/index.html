What is Whisper?

A plain-English explainer of the speech recognition model behind Murmur, and why it can run on a phone.

What is OpenAI Whisper?

Whisper is an open-source automatic speech recognition model released by OpenAI in September 2022. It was trained on 680,000 hours of multilingual audio collected from the web, and it can transcribe speech in many languages and translate it into English. Because the model weights are public, apps like Murmur can run it on your own device.

How Whisper works

Whisper is a transformer model with two halves. The encoder listens: it turns 30-second windows of audio into an internal representation. The decoder writes: it predicts the text one token at a time, along with timestamps. OpenAI describes the training data and results in its Whisper announcement and the paper Robust Speech Recognition via Large-Scale Weak Supervision.

Model sizes

Whisper comes in sizes from Tiny to Large. Bigger models are more accurate but need more memory and time.

ModelUse in Murmur
Large v3 TurboRecommended. Compressed to about 632 MB.
SmallLighter option, about 500 MB.
TinyNot offered. Too inaccurate for real notes.

Large v3 Turbo, released in 2024, keeps the large encoder but uses a much smaller decoder, which makes it far faster than Large v3 with only a small drop in accuracy.

How Whisper runs on iPhone and Mac

Murmur uses WhisperKit, an open-source framework from Argmax that converts Whisper to Core ML so it can use Apple's Neural Engine and GPU. That is what lets a full Large-class model transcribe on an iPhone, with no server involved. Read more about Murmur's on-device transcription.

Limits to know

  • Accuracy drops with heavy background noise, crosstalk and strong music.
  • Rare names and jargon can be misspelled; a custom vocabulary helps.
  • Whisper does not identify speakers by itself. In Murmur you label speakers in the editor.

FAQ

Frequently asked questions

Is Whisper free?

Whisper's code and model weights are open source under the MIT license. Apps built on it may charge for their own features.

Does Whisper need the internet?

No. Once the model is on your device it runs offline. Cloud APIs that use Whisper do need the internet, because they run it on their servers.
