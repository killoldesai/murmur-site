Is there a transcription app for iPad that works offline?

Murmur runs on iPad with the same on-device Whisper engine as on iPhone, so it transcribes offline without uploading audio. The iPad layout puts the library, notes and transcript side by side, with a summary and talk-time panel and a drop zone for importing files.
